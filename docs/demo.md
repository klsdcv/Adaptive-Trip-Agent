# Local demo

1. 백엔드 테스트로 synthetic 시나리오를 확인합니다.

   ```powershell
   & .venv\Scripts\python.exe -m pytest -q
   ```

2. 웹 앱을 실행합니다.

   ```powershell
   npm --prefix web run dev
   ```

3. 일정 입력란에 여러 장소와 시간을 자연어로 입력하고, 초안에서 시간대와 장소를 확인한 뒤 확정합니다.

4. 여행을 불러온 뒤 피드백 버튼으로 지연·휴무·비·피로 이벤트를 보내면 상태가 저장되고 재계획 run 상태를 polling합니다.

5. 새 제안이 나오면 후보를 비교하고 선택하거나 거절합니다. 선택 전 원래 일정은 유지됩니다.

외부 API를 사용하려면 `.env`에 키를 설정하고 서버를 재시작하세요. 키 값은 저장소나 브라우저 번들에 포함하지 않습니다.
